# Text Hide Tool

## Why?
I made this tool for help with memorizing definitions (for example, you can create cards in tools like Anki - hidden definition on front of card, visible difinition on back).

## 📦 Installation

1. Prerequisites
- Python 3.6 or higher

2. Install Dependencies
- **pip install pyperclip**
